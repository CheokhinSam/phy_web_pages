⚖️ 力的合成與分解

實驗介紹

這個實驗讓你看到兩個力如何「合在一起」變成一個合力，以及一個力如何「拆開」變成兩個分力。你可以調整兩個力的大小和它們之間的夾角，觀察合力的大小和方向如何變化。

畫面同時展示兩種方法：左邊是「平行四邊形法」——兩個力構成平行四邊形的兩邊，對角線就是合力；右邊是「三角形法」——兩個力首尾相連，從起點到終點就是合力。這兩種方法算出來的結果完全一樣。

物理知識

核心概念

力是「向量」，有大小也有方向。兩個力加在一起，不能只把數字相加，還要考慮方向。

想像你和朋友一起推一張桌子。如果你們往同一個方向推，力量會疊加得很大；如果你們往相反方向推，力量會互相抵消；如果你們往不同角度推，合力就介於兩者之間。

核心公式

\[F = \sqrt{F_1^2 + F_2^2 + 2F_1 F_2 \cos\theta}\]
  • $F_1$、$F_2$：兩個分力的大小（單位：N）
  • $\theta$：兩個力之間的夾角
  • $F$：合力的大小

白話來說：合力不只看兩個力有多大，還要看它們「夾幾度」。夾角越小（方向越接近），合力越大；夾角越大（方向越相反），合力越小。

從圖表看出端倪

  • 夾角 0°：兩個力同方向，合力 = F₁ + F₂（最大值）
  • 夾角 90°：用畢氏定理，合力 = √(F₁² + F₂²)
  • 夾角 180°：兩個力反方向，合力 = F₁ - F₂ （最小值）
  • 夾角 120° 且 F₁ = F₂：合力剛好等於分力大小

生活中的力合成與分解

  • 🧗 攀岩者的安全安全繩：繩子受到的力可以分解為水平和垂直兩個分量，工程師用這個計算繩子夠不夠強
  • ⛵ 帆船逆風航行：風力分解為推動船前進的分力和讓船側傾的分力，水手利用這個原理走之字形路線
  • 🏋️ 搬沙發上樓：斜坡上的重力分解為沿斜面往下的分力和壓緊斜面的分力，角度越陡，沿斜面的分力越大
  • 🪁 風箏飛行：風力分解為升力和阻力，風箏線的張力也可以分解為水平和垂直分量
