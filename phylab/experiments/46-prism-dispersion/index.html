🔺 稜鏡折射、最小偏向角與色散

實驗介紹

畫面上是一個頂角 A = 60° 的三角形稜鏡。黃色光線從左邊射入，在左面折射、在稜鏡裡走一段直線，再從右面折射出去；藍色是稜鏡裡的光線，灰色虛線是法線。

稜鏡上只標 θ₁、θ₄、d、A 這些符號；數值集中在右上角的讀數框，右側「數據與圖表」的卡片也有同一組數字。

「入射角 θ₁」滑桿的範圍是 30° 到 85°。下面的「情境」可以一鍵跳到最小偏向角、幾個常用角度，或「全反射示範」。

用「光線」切換「單色光」與「色散（七色光）」。拖動 θ₁ 與折射率 n，看偏向角 d 怎麼變；把 θ₁ 調到最小偏向角 d_min 附近，稜鏡裡的光線會平行底邊。

色散模式也可以拉 n：這裡的 n 是中央（黃光）的折射率，七色會跟著它一起平移，紅光與紫光的實際 n 顯示在讀數框與右側卡片。

入射角太小而折射率太大時，光在右面會全反射、出不去：讀數框的 θ₄ 與 d 變成「—」，光線在右面折回稜鏡裡。切到「全反射示範」，或把 θ₁ 拉到 30°、n 拉到 1.60，就看得到。

按下「開始 START」，入射角會慢慢掃過最小偏向角附近，偏向角先變小、再變大；光脈衝也會沿著中央那條光線走一遍。

物理知識

光在稜鏡裡走了兩次折射

稜鏡有兩個互相傾斜的折射面。光從左面進入時，由空氣進入玻璃，折射線靠近法線；從右面離開時，由玻璃回到空氣，折射線遠離法線。兩次偏折的方向相同，所以出射線整體往稜鏡的底邊偏。

設頂角是 $A$，光線在左面的入射角是 $\theta_1$、折射角是 $\theta_2$，在右面的入射角是 $\theta_3$、出射角是 $\theta_4$。由幾何關係

\[\theta_2+\theta_3=A\]

偏向角

入射線與出射線的夾角叫偏向角，記作 $d$。由三角形外角關係

\[d=\theta_1+\theta_4-A\]

偏向角不是固定值：它隨著入射角 $\theta_1$ 改變。把 $\theta_1$ 從小到大掃一遍，$d$ 會先減小、到某個角度最小、然後再變大。

最小偏向角

當入射角等於出射角

\[\theta_1=\theta_4\]

時，偏向角最小，記作 $d_{\min}$。此時稜鏡內的光線平行於底邊，而且 $\theta_2=\theta_3=A/2$。

把 $\theta_2=A/2$、$\theta_1=(A+d_{\min})/2$ 代入斯涅爾定律，得到

\[n=\frac{\sin\frac{A+d_{\min}}{2}}{\sin\frac{A}{2}}\]

反過來，已知折射率時

\[\theta_{1,\min}=\sin^{-1}\left(n\sin\frac{A}{2}\right)\] \[d_{\min}=2\theta_{1,\min}-A\]

這就是用稜鏡量折射率的方法：量出頂角 $A$ 與最小偏向角 $d_{\min}$，就能算出 $n$。

為什麼最小偏向時內部光線平行底邊

光路是可逆的。如果 $\theta_1=\theta_4$，把光線反過來走，它會沿著同一條路徑回去，所以光線在稜鏡裡對稱於頂角的角平分線。等腰三角形的對稱線垂直平分底邊，因此內部光線平行底邊。

色散

同一種介質對不同顏色的光，折射率不完全相同。一般來說，紫光的折射率最大，紅光的折射率最小。

由斯涅爾定律，折射率愈大，光線偏折得愈多。所以同一束白光經過稜鏡後：

  • 紫光偏得最多。
  • 紅光偏得最少。
  • 中間依次是橙、黃、綠、藍、靛。

不同顏色分開的現象叫色散，分開後形成的光帶叫光譜。

色散模式裡的 n

七色光的 n 不是七個各自固定的數字，而是以黃光的 n 為中央、依固定差距展開：紅光比中央小 0.02、橙光小 0.01、黃光不變、綠光多 0.01、藍光多 0.02、靛光多 0.03、紫光多 0.04。

所以預設的 $n=1.50$ 對應紅光 $1.48$、紫光 $1.54$；把滑桿拉到 $1.55$，七色就一起變成 $1.53$–$1.59$。這組差距只是為了把色散畫清楚而選的數值，不是某一種玻璃的精確數據。重要的是紫光的 n 比紅光大，所以不論中央的 n 是多少，紫光的偏向角都比紅光大。

什麼時候會全反射

光從稜鏡內部射向空氣時，如果入射角大於臨界角

\[\theta_C=\sin^{-1}\frac{1}{n}\]

右面就沒有折射線，光全部反射回稜鏡裡。稜鏡內的入射角是 $\theta_3=A-\theta_2$，而 $\theta_1$ 愈小、$\theta_2$ 也愈小，所以 $\theta_1$ 太小反而會讓 $\theta_3$ 超過臨界角。折射率 $n$ 愈大，臨界角愈小，也愈容易全反射。

這一頁的範圍是 $\theta_1=30^\circ$–$85^\circ$、$n=1.30$–$1.60$。$n=1.60$ 時入射角小於約 $35.6^\circ$ 就會全反射；$n=1.50$ 的門檻是約 $27.9^\circ$。色散模式用七個不同的 $n$：在預設的 $n=1.50$（紅 $1.48$、紫 $1.54$）下，$30^\circ$ 附近紫光會先全反射，紅光還出得去——畫面上會看到紫色的光停在稜鏡裡面。把中央的 $n$ 拉高，會有更多顏色一起消失。

發生全反射時沒有出射線，也就沒有出射角 $\theta_4$ 與偏向角 $d$；卡片與讀數框會顯示「—」，而不是硬填一個數字。

生活中的例子

  • 雨後彩虹：陽光進入水滴，在水滴內反射一次，再折射出來；水滴同時扮演稜鏡與鏡子，把白光散成彩色。
  • 牛頓用稜鏡把白光分解成光譜，證明白光本身包含各種顏色，而不是稜鏡「染」上去的。
  • 透鏡的色差：不同顏色的焦距略有不同，所以同一個透鏡的成像會有一點彩色邊緣。
