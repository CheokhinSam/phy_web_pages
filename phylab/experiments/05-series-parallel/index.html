💡 串聯電路與並聯電路

實驗介紹

本實驗比較串聯電路與並聯電路的特性。您可以切換串聯/並聯模式，並增加或減少燈泡數量（1~6 個），觀察燈泡亮度的變化、總電阻、總電流與總功率的即時數據。

畫面上的燈泡亮度會隨實際功率變化——功率越大越亮，功率越小越暗。

物理知識與公式

串聯電路

所有元件依序連接在同一條迴路上：

\[R_{\text{total}} = R_1 + R_2 + \cdots + R_n\]
  • 電流 $I$ 相同：$I = \frac{V}{R_{\text{total}}}$
  • 電壓分配：$V_i = I \cdot R_i$
  • 每個燈泡功率：$P_i = I^2 R$

並聯電路

所有元件並列連接，各自有獨立迴路：

\[\frac{1}{R_{\text{total}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}\]
  • 電壓 $V$ 相同：每個燈泡都得到完整電源電壓
  • 電流分配：$I_i = \frac{V}{R_i}$
  • 每個燈泡功率：$P_i = \frac{V^2}{R}$

燈泡亮度

燈泡亮度取決於實際消耗功率：

\[P = I^2 R = \frac{V^2}{R}\]

串聯時增加燈泡 → 總電阻增大 → 電流減小 → 每個燈泡變暗。

並聯時增加燈泡 → 總電阻減小 → 每個燈泡仍得到相同電壓 → 亮度不變。

📊 實驗探究思考

  1. 在串聯電路中，每增加一個燈泡，總電阻如何變化？每個燈泡的亮度有什麼變化？
  2. 在並聯電路中，每增加一個燈泡，總電阻如何變化？每個燈泡的亮度有什麼變化？
  3. 同樣使用 3 個燈泡，串聯和並聯哪種配置下總功率較大？為什麼？
  4. 如果電源電壓固定，哪種電路在增加燈泡時會讓燈泡變得更暗？試用公式 $P = V^2 / R$ 解釋。
