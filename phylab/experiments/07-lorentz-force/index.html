🧲 洛倫茲力

實驗介紹

本實驗模擬帶電粒子在均勻磁場中的運動。當粒子速度垂直於磁場時，洛倫茲力提供向心力，使粒子做圓周運動。

畫面中：

  • ⊗ 符號：磁場方向（垂直進入屏幕）
  • 紅色/藍色球：正/負電荷粒子
  • 黃色箭頭：洛倫茲力方向
  • 虛線圓：預測軌道

物理知識與公式

洛倫茲力

帶電粒子在磁場中受到的力為：

\[\vec{F} = q\vec{v} \times \vec{B}\]

當 $\vec{v} \perp \vec{B}$ 時，力的大小為：

\[F = qvB\]

圓周運動

洛倫茲力提供向心力：

\[qvB = \frac{mv^2}{r}\]

因此：

\[r = \frac{mv}{qB}\]

週期與角速度

\[T = \frac{2\pi r}{v} = \frac{2\pi m}{qB}\] \[\omega = \frac{qB}{m}\]

重要結論：週期 T 與速度 v 無關！

關鍵特性

因素 變化 半徑變化 週期變化
磁場加倍 B → 2B r → r/2 T → T/2
速度加倍 v → 2v r → 2r T 不變
質量加倍 m → 2m r → 2r T → 2T
電荷加倍 q → 2q r → r/2 T → T/2

迴旋加速器原理

由於 T 與 v 無關，可以用固定頻率的交流電場加速粒子。每轉一圈，粒子被加速兩次，速度增加但週期不變。

\[T_{cyclotron} = \frac{2\pi m}{qB}\]

方向判斷（左手定則）

  1. 磁場 B 穿入掌心
  2. 四指指向正電荷運動方向（負電荷反向）
  3. 大拇指指向力的方向

應用

  • 迴旋加速器：加速粒子到高能量
  • 質譜儀：根據 m/q 分離同位素
  • 磁瓶：約束電漿
  • 地球磁場：保護地球免受太陽風侵襲
