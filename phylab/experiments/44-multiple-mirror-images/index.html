🪞 平面鏡的多次反射成像

實驗介紹

畫面上有兩面斜斜的平面鏡 A、B，在 O 點夾出一個角 θ。藍色點是物體，橘色與紫色的點是它被鏡子來回反射後形成的像，編號從 1 開始；虛線圓通過所有像。

用「兩面鏡子的夾角 θ」切換角度，像的數目、位置與顏色會跟著改變。橘色代表反射奇數次（左右相反），紫色代表反射偶數次（左右和物體相同）。

拖動「物體在夾角中的位置」，讓物體靠近或遠離分角線。角度是 90° 這種 n 為奇數的情形時，物體跨過分角線的那一刻，像的數目會少一個。

按下「開始 START」，物體會沿著圓弧慢慢來回，自動掃過分角線。

物理知識

兩面平面鏡為什麼會生出很多像

物體放在兩面平面鏡的夾角裡。光線可以先被鏡 A 反射，再被鏡 B 反射，甚至來回反射好幾次。每一次反射，眼睛沿著反射線的反方向看回去，都會看到一個新的像。

所以除了「鏡 A 裡有一個像、鏡 B 裡有一個像」之外，還會出現「鏡 A 裡的像在鏡 B 裡又有一個像」這種一層一層的像。

像的數目：n = 360° / θ

設兩面鏡子的夾角是 $\theta$，令

\[n=\frac{360^\circ}{\theta}\]

像的數目要分三種情形：

  • n 是偶數：像的數目是 $n-1$。
  • n 是奇數，物體在分角線上：像的數目是 $n-1$。
  • n 是奇數，物體不在分角線上：像的數目是 $n$。

例如兩面鏡子夾 $90^\circ$，$n=4$ 是偶數，像的數目是 $4-1=3$。夾 $60^\circ$，$n=6$ 是偶數，像的數目是 5。

如果 $n$ 不是正整數，例如 $\theta=50^\circ$ 時 $n=7.2$，就沒有這麼簡單的整數公式，要把每一次反射的像畫出來數。

為什麼 n 為偶數時少一個

$n$ 為偶數時，反射到最後，某一個像會和物體（或另一個像）重合，不能算成兩個不同的像。所以實際看到的像比 $n$ 少一個。

物體在分角線上時，左右兩邊的像對稱重合，也會少一個；物體離開分角線，兩邊的像分開，才會補回那一個。

所有像都在同一個圓上

每一次反射都是把點對鏡面作對稱。對稱不改變點到交點 O 的距離，只改變它的方向。物體到 O 的距離是 $r$，所以每一個像到 O 的距離也都是 $r$。

因此所有像都落在以 O 為圓心、半徑 $r$ 的圓上；物體也在這個圓上。畫面上的虛線圓就是這個圓。

左右為什麼會反過來

一次反射會把左右對調，所以反射奇數次的像左右相反；再反射一次又對調回來，所以反射偶數次的像左右和物體相同。

畫面上橘色的像是奇數次反射，紫色的像是偶數次反射。

像不會再被後面的鏡子反射

只有落在鏡子前面的點，才能被那面鏡子反射。某個像如果落在某面鏡子的背後，它就不能再被那面鏡子成像——這也是為什麼像的數目不會無限增加，而是在某一步停下來。

生活中的例子

理髮店把兩面鏡子相對擺放，你坐在中間，就可以從其中一面鏡子看到自己的背面，再從另一面鏡子看到更後面的角度。夾角愈小，來回反射的次數愈多，看到的像也愈多；萬花筒就是把這個效果排成一圈。

📊 實驗探究思考

  1. 兩面鏡子的夾角 θ 變小，像的數目為什麼會變多？
  2. n = 360° / θ 算出來是 6 時，為什麼像的數目是 5 而不是 6？
  3. 物體在分角線上與不在分角線上，像的數目為什麼差一個？
  4. 為什麼所有像都落在同一個圓上？圓心在哪裡？
  5. 哪一些像的左右和物體相同？哪一些左右相反？這和光線反射幾次有什麼關係？
  6. 把 θ 調成 50°，n = 7.2 不是正整數，為什麼不能直接套公式？
  7. 理髮店的兩面鏡子為什麼可以讓你看到自己的後腦？
