⚙️ 機械效率

實驗介紹

滑輪組可以省力。那是不是也省了功？力從 400 N 變成 100 N，少了 300 N——距離當然變長了， 但那又怎樣，反正力小了那麼多。

畫面上把這件事變成一條長度：

  • 中央並排兩條堆疊長條。下面綠色的是有用功（真的把東西提上去的功），上面紅色的是額外功（白做的部分），兩塊疊起來的總高度就是總功。
  • 左邊那條固定是 n = 2 的對照組，右邊那條是你現在選的繞法。
  • 把「摩擦」留在 0，切換 n——兩條的總高度一模一樣，只是綠紅交界的位置不同。
  • 把摩擦拉起來：右邊那條會高出左邊，高出來的那一截就是多做的功。
  • 右邊那張圖是機械效率 η 對段數 n。沒有摩擦時它是一條水平線。

物理知識

三種功

用機械把東西提上去的時候，能量分成三份：

名稱 是什麼 怎麼算
有用功 $W_{有}$ 真的達成目的的那一部分——把物體提上去 $W_{有} = G\,h$
額外功 $W_{額}$ 為了用這個機械而不得不多做的 $W_{額} = G_{動}h + f\,s$
總功 $W_{總}$ 你實際出的力乘上你手走的距離 $W_{總} = F\,s$

關係只有一條：

\[W_{總} = W_{有} + W_{額}\]
  • $G$：物重（N）　$h$：物體上升的高度（m）
  • $G_{動}$：動滑輪＋框的重量（N）
  • $f$：摩擦阻力（N）　$s$：繩端（手）移動的距離（m）
  • $F$：手的拉力（N）

額外功的兩個來源，就是畫面上那兩支滑桿：

  1. 動滑輪自己的重量 $G_{動}$：它跟著物體一起上升 $h$，所以要作 $G_{動}h$ 的功
  2. 摩擦 $f$：繩子在滑輪上滑過去的每一段都要磨，滑過的距離是 $s$，所以要作 $fs$ 的功

注意摩擦那一項是乘 $s$（手走的距離），不是乘 $h$。

機械效率

\[\eta = \frac{W_{有}}{W_{總}}\]

$\eta$（讀作 eta）是一個沒有單位、永遠小於 1 的數，通常寫成百分比。它回答的是：「我出的力氣裡，有幾成真的用在正事上？」

$\eta = 80\%$ 的意思是：你作了 100 J 的功，其中 80 J 真的把東西提上去了，另外 20 J 拿去提動滑輪和對抗摩擦了。

$\eta$ 永遠小於 1，因為額外功永遠存在——動滑輪有重量、繩子有摩擦。$\eta = 1$ 只存在於「理想機械」那個假想的世界裡。

為什麼 η 和 n 無關

不計摩擦（$f = 0$）的時候：

\[\begin{aligned} \eta = \frac{W_{有}}{W_{總}} &= \frac{G\,h}{G\,h + G_{動}h} \\[2pt] &= \frac{G\,h}{(G + G_{動})\,h} \\[2pt] &= \frac{G}{G + G_{動}} \end{aligned}\]

$h$ 約掉了，$n$ 從頭到尾沒有出現。

把 n 從 2 切到 5、把高度從 5 cm 拉到 40 cm，$\eta$ 一動也不動。「滑輪愈多、效率愈差」聽起來很合理——但在沒有摩擦的世界裡，它是錯的。

那為什麼現實中繩子繞愈多段、效率真的愈差？因為摩擦。

\[\begin{aligned} \eta &= \frac{G\,h}{G\,h + G_{動}h + f\,s} \\[2pt] &= \frac{G}{G + G_{動} + n\,f} \end{aligned}\]

（第二行把 $s = n\,h$ 代進去。）

摩擦項 $f\,s$ 換成 $n\,h$ 之後，$n$ 進到分母裡了——而且只從這裡進來。

這就是為什麼摩擦那一支滑桿可以一路拉到 0：摩擦是 $n$ 的唯一入口。把摩擦關掉，$n$ 就從效率的公式裡整個消失；把它打開，$\eta$ 才會開始隨 $n$ 往下掉。

省力不省功

把兩個數字並排看。$G = 400$ N、$G_{動} = 60$ N、不計摩擦，物體上升 $h$：

$n$ 手的力 $F$ 手走的距離 $s$ $W_{總} = Fs$ $\eta$
2 230.0 N $2h$ $460h$ 87.0%
3 153.3 N $3h$ $460h$ 87.0%
4 115.0 N $4h$ $460h$ 87.0%
5 92.0 N $5h$ $460h$ 87.0%

力掉到四成，總功一格都沒動，效率也一格都沒動。

省力和費距離是同一件事的兩面：$F$ 乘上 $s$ 的時候，$n$ 剛好約掉。

從圖表看出端倪

右邊那張圖是機械效率 $\eta$ 對段數 $n$：

  • $f = 0$：一條水平線。不管你繞幾段，$\eta$ 都一樣（$\eta = G/(G+G_{動})$）
  • $f > 0$：一條往下的斜線。$n$ 愈大，繩子滑過的總距離 $s = nh$ 愈長，摩擦吃掉的就愈多
  • 把摩擦滑桿從 0 拉起來，你會親眼看到那條線從平的變成斜的——中間沒有任何過渡，因為那就是分母多了一項 $nf$ 而已

生活中的機械效率

現象 為什麼
🏗️ 起重機的吊鉤 滑輪組省力，但鋼索和滑輪之間的摩擦讓 $\eta$ 只有六七成
🚗 汽車的傳動 引擎的功經過變速箱、傳動軸、輪胎，一層一層損耗，最後只剩一部分推到路上
🚲 自行車的鏈條 忘了上油，$\eta$ 就掉——同樣的力氣騎得更慢，差別就在摩擦
🪝 電梯的配重 配重塊讓 $\eta$ 大幅提高，因為它分擔了很大一部分的重量
🌊 抽水機把水抽上山 $\eta$ 決定要付多少電費——50% 的意思是一半的電拿去加熱水和震動了
🥢 用筷子夾菜 費力槓桿，$\eta$ 當然小於 1——但你換到了「精細」，那個價值不在 $\eta$ 裡

📊 實驗探究思考

  1. 把「摩擦阻力」留在 0，然後把「繩子繞成幾段」從 2 一路切到 5。兩條長條的總高度有沒有變？左邊綠色那塊（有用功）有沒有變？紅色的那一塊呢？
  2. 承上題：n 從 2 變到 5 的時候，手的力 F 從 230 N 掉到 92 N（省了很多！），可是 η 那張卡片一動也不動。用 $\eta = \dfrac{G}{G + G_{動}}$ 說明為什麼它一定不會動。
  3. 現在把「摩擦阻力」慢慢從 0 拉起來。右邊那張圖原本是一條水平線，當場變成往下的斜線——n 愈大掉得愈多。為什麼摩擦對 n 大的繞法特別不友善？（提示：n 大的時候，繩子總共滑過多長的距離？）
  4. 把「動滑輪＋框重」拉到 0，η 會變成 100%。現實中做得到這件事嗎？如果做不到，那 $\eta < 1$ 這條規則真正的意思是什麼？
  5. 把物體上升的高度從 5 cm 拉到 40 cm。有用功變了 8 倍，但 η 一點都沒變。既然 η 和 n 無關、和 h 也無關，那它是被什麼決定的？
