🪢 繩波的折射與透射

實驗介紹

把兩段粗細不同的繩子綁在一起拉緊，然後從細的那一端抖一個波過去。波跑到接點的時候，一部分反射回去，一部分透射過去——不是全過，也不是全彈回來，而是同時發生。只要介質變了，介面就一定同時產生反射波和透射波。

畫面上有兩條 lane：上面是實際的繩子（左右兩段顏色不同），下面是分解——入射、反射、透射三條各自畫出來。分解那條把入射波一路畫到繩子右端，那是「如果沒有接點，它本來會繼續走」的虛像。

左邊可以調兩段的線密度 μ₁、μ₂（張力兩邊當然一樣）與振幅 A，並切換兩個模式：

  • 單一脈衝（預設）：送出一個脈衝，看它當場裂成反射與透射兩個脈衝——「入射／反射／透射振幅」三張卡片就是它的重點。
  • 連續波：看波長——透射過去的那一段波長會變，但頻率一個都沒少。

脈衝模式可以調脈衝寬度 w，連續波模式可以調頻率 f。

物理知識

什麼變、什麼不變

物理量 過介面時 為什麼
頻率 f 不變 介面兩側是同一條繩子連著，左邊每秒被抖幾下，右邊就被拉幾下
波速 v 改變 $v = \sqrt{T/\mu}$，張力一樣但線密度變了
波長 λ 改變 $v = f\lambda$，$f$ 不變、$v$ 變了，$\lambda$ 只能跟著變
\[\frac{\lambda_1}{\lambda_2} = \frac{v_1}{v_2} = \sqrt{\frac{\mu_2}{\mu_1}}\]

繩子變重（μ 變大）→ 波跑得慢 → 波長變短，但一秒鐘還是一樣幾個波。脈衝版本講的是同一件事：同樣的時間變化換到波速 $v_2$ 的繩子上，空間上就得伸縮 $v_2/v_1$ 倍——所以透射脈衝的寬度變成 $v_2/v_1$ 倍。

部分反射：能量怎麼分

介面上位移和斜率都必須連續，這兩個條件就把比例鎖死了：

\[r = \frac{v_2 - v_1}{v_1 + v_2} \qquad \tau = 1 + r\]

其中 $P = \tfrac{1}{2}Z\omega^2A^2$ 是波的能量通量（$Z = \sqrt{T\mu}$ 是阻抗）。

  • $r$：反射係數，反射波的振幅是 $rA$；$\mu_1 < \mu_2$ 時 $r < 0$，反射脈衝上下反轉
  • $\tau$：透射係數，透射波的振幅是 $\tau A$，一定和入射同號
  • 能量：反射拿走 $r^2$，透射拿走 $1 - r^2$，兩者加起來永遠是 1

這正是右邊「反射能量比」卡片在顯示的東西：把兩段繩子調成一樣（μ₁ = μ₂），它會變成 0.0%，因為根本沒有介面。

（這式子用速度寫，只在兩邊張力相同時成立；張力不同要用阻抗版 $r = (Z_1-Z_2)/(Z_1+Z_2)$。）

一維沒有「偏折」

一維的繩波不會轉彎——繩子只有一個方向，波只能沿著它跑。水波會偏折是因為它是二維的：波前斜斜撞上界面時，一部分先變速，整條波前就被扭轉了，這就是 Snell 定律（由「水波折射」那一頁負責）。

生活中的介面

  • 🪢 繩子接橡皮筋：波從繩子傳到橡皮筋時會變慢、波長變短，同時有一部分彈回來
  • 🌊 淺灘上的浪：浪從深海進入淺海，速度變慢、波長變短、波高變高（前後的能量擠在一起），最後才碎掉
  • 🩺 超音波與地震波：工程師靠「反射回來多少、透射過去多少」判斷地底或人體內部的結構，用的就是這一組係數

📊 實驗探究思考

  1. 「頻率 F」的卡片不管你把 μ₁、μ₂ 怎麼調，一直都是你設定的那個值。為什麼頻率可以不變，波速和波長卻要變？
  2. 把 μ₂ 調得比 μ₁ 大很多，透射波的波長是變長還是變短？和波速的變化方向一樣嗎？
  3. 反射能量比會隨 μ₁ 與 μ₂ 的差距變大而增加。如果兩段繩子完全一樣（μ₁ = μ₂），這個數字會是多少？實際調調看。
  4. 波在接點上「分裂」成兩條。如果反射的拿走了一部分能量，透射的拿走多少？（提示：加起來是多少？）
  5. 把繩子接上一根彈簧（張力一樣但重得多），你覺得反射會接近固定端還是自由端？
  6. 切成「單一脈衝」，盯著反射與透射那兩個脈衝看。它們的振幅、寬度、行進方向各和原來的脈衝差在哪裡？
