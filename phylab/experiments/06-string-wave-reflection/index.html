🪢 繩波的反射

實驗介紹

抓住跳繩的一端，另一端請人綁在柱子上，抖一個波浪出去。波浪撞到柱子反彈回來的時候，長什麼樣子？

回來的波是上下顛倒的。 送上去一個波峰，回來的是波谷。

更奇怪的是，如果另一端不是綁死，而是穿過一個光滑的環、可以自由上下滑動，反彈回來的波就完全不會顛倒。同樣的波、同樣的繩子，只差在端點的固定方式。

畫面上有兩條 lane：上面是實際的繩子（入射與反射疊在一起的結果），下面是分解——兩者各自畫出來。分解那條把入射波畫到端點右邊去，那是「如果沒有端點，它本來會繼續走過去」的虛像，方便對照反射波到底翻了沒有。

左邊可以選端點類型與波形，也可以調振幅、脈衝寬度、頻率。

物理知識

核心概念：取決於端點能不能動

  • 固定端：端點被釘死，位移永遠是零。波傳到這裡時繩子必須把自己拉回零，結果就是產生一個完全相反的波往回跑。反射波和入射波在端點處大小相等、方向相反，加起來剛好是零。
  • 自由端：端點套在光滑桿上可以自由滑，沒有東西把它拉回零，繩子反而動得最厲害。反射波和入射波在端點處方向相同，加起來變成兩倍振幅。

核心公式

用反射係數 $r$ 把兩件事寫成同一個形式：

\[r = \frac{Z_1 - Z_2}{Z_1 + Z_2} \qquad Z = \sqrt{T\mu}\]
  • 固定端：等於接到一段無窮重的繩子（$Z_2 \to \infty$），$r = -1$ → 相位反轉
  • 自由端：等於接到一段沒有質量的繩子（$Z_2 \to 0$），$r = +1$ → 不反轉

$Z$ 叫做阻抗，是繩子「抵抗被晃動」的程度。反射就是兩個阻抗不匹配的地方一定會發生的事。

換成形狀來想

端點 端點必須滿足 反射波只好 結果
固定端 位移 $y = 0$ 和入射波完全相反 波峰變波谷
自由端 斜率 $\partial y/\partial x = 0$ 和入射波完全相同 波形原封不動

自由端那個「斜率 = 0」就是繩子在端點是水平的。如果末端是斜的，張力就會有個垂直分量把環往上或往下拉，環就會滑動，所以平衡時末端一定是平的。

連續波：駐波長出來了

切成「連續波」、端點選固定端，會看到一件新事情：波一直送過去、一直反射回來，兩者在繩子上疊加，最後繩子不再有波跑出去，只是在原地分段上下跳。靠近牆的地方幾乎不動（固定端是節點），每隔半個波長就再出現一個不動的點——這就是駐波。自由端則相反：端點是腹點，動得最厲害，繩子看起來像在甩尾。

生活中的反射

  • 🪢 甩跳繩綁在柱子上：抖一下，回來的波浪是顛倒的
  • 🎸 弦樂器的琴橋：弦在琴橋那一端幾乎不能動，所以兩端都是固定端——這正是弦上能形成駐波、發出聲音的原因
  • 🩺 超音波檢查：聲波進到人體，遇到不同密度的組織就反射一部分回來。反射特別強的地方就代表那裡「阻抗不匹配」——可能是骨頭，也可能是腫瘤

📊 實驗探究思考

  1. 脈衝撞上固定端之後回來的形狀，和撞上自由端之後回來的形狀，最大的差別是什麼？把兩次都跑一遍再回答。
  2. 固定端的「端點位移」卡片一直顯示 0.00。如果端點不能動，那入射波的能量跑到哪裡去了？
  3. 自由端反彈的那一瞬間，端點的位移卡片會顯示多少？為什麼會超過你設定的振幅？
  4. 切成「連續波」、端點選固定端。等波跑滿整條繩子之後，繩子變成什麼圖形？為什麼靠近牆壁的地方幾乎不動？
  5. 把同樣的實驗換成「一端綁在牆上、另一端綁在彈簧上」，你覺得反射回來的波會比較像固定端還是自由端？
