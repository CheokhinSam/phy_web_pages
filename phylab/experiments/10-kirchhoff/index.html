實驗介紹

兩顆電池、三顆電阻、兩個迴路，中間那一支同時屬於左右兩個迴路——它沒辦法拆成「串聯」或「並聯」。

這種電路只能靠兩個定律硬算：

\[\sum I = 0 \qquad \sum V = 0\]

按開始之後，畫面上的電流點會照著解出來的方向流動。把「右電池 ε₂」慢慢拉大，中間那一支的電流會先縮到零、然後整支掉頭——這是畫面上最值得看的一刻。

物理知識

ΣI = 0：電荷守恆

流進一個節點的電荷，必須全部流出去。不然電荷會在那個點上堆積起來，而電荷堆積就是電壓改變，電壓一改變電流就跟著改——它會自己調整到不堆積為止。

這就是 ΣI = 0 的來源，不是「因為公式這樣寫」，是因為電荷不會無中生有、也不會消失。

ΣV = 0：能量守恆

繞任何一圈回到出發點，位能變化必須是零——你回到了同一個地方，電位就只能有同一個值。

所以一圈裡「電位被抬高的總量」必須等於「電位被拉低的總量」。電池負責抬高，電阻負責拉低。

怎麼用這兩個定律解題

  1. 假設每個支路電流的方向（猜錯沒關係，算出來是負的就代表猜反了）
  2. 對每個節點寫 ΣI = 0
  3. 對每個獨立迴路寫 ΣV = 0
  4. 解聯立方程式

按開始它就跑給你看。但步驟 1 那個「猜錯沒關係」才是重點：中間那一支的方向不是用看的就知道的，要靠算。

為什麼串並聯在這裡不能用

串聯的前提是「同一條路上、電流相同」，並聯的前提是「同一對節點、電壓相同」。

中間那一支 $R_3$ 的兩端是 Q 和 T，但它上面那一點 Q 同時被左邊的 $R_1$ 和右邊的 $R_2$ 接著——它不與任何一顆電阻「同一對節點」，也不與任何一顆「同一條路」。它兩個都不是。

生活中的例子

  • 🏠 家裡的配電箱。中性線把許多迴路接到同一個點，那一點上的電流和必須是零——不然整條線會帶電。
  • 🔌 多顆電池並聯供電。電動勢不一樣的電池並在一起，比較強的那顆會給比較弱的那顆充電，中間那一支的電流方向就是這樣決定的。
  • ⚡ 電路模擬軟體。SPICE 這類軟體的核心就是對每個節點列 ΣI = 0，跟這裡做的事一模一樣。
  • 📱 手機的電源管理。充電器、電池、系統負載接在同一個節點上，晶片要即時算出每一支該分到多少電流。

📊 實驗探究思考

  1. 這個電路的三顆電阻，有哪兩顆是串聯的嗎？有哪兩顆是並聯的嗎？先想清楚再按開始。
  2. 中間那一支的電流是從上往下還是從下往上？把「右電池 ε₂」慢慢拉大，什麼時候它會改變方向？改變之前那一刻發生了什麼事？
  3. 「節點 Q 的 ΣI」那張卡片永遠顯示 0。它是被算出來的，還是被規定成 0 的？這兩者有什麼差別？
  4. 兩顆電池的 ＋ 端故意接在相反的方向。如果把它們改成同向，中間那一支還會反向嗎？為什麼？
  5. 家裡的配電箱裡有一條「中性線」把很多迴路接在一起。那一點上的電流也滿足 ΣI = 0 嗎？
