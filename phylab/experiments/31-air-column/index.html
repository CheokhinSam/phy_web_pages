🎺 開管與閉管的空氣柱駐波

實驗介紹

畫面上有兩條並排的圖。上面是位移圖：每一點的高度是「這個位置的空氣往右跑了多少」——縱波沒有上下起伏，這是同一個函式的另一種長相。下面是管內的空氣：一圈圈質點沿著管子左右來回振動，擠在一起的地方色帶就深。

  • 管子可以切換開管（兩端開口）與閉管（左端封閉、右端開口），切到閉管時左邊會多出一面牆。紅點是波節、綠圈是波腹（會跟著波腹上下跑），藍色括號量的是相鄰兩個波腹的距離 λ/2；切到閉管時它改量封閉端到第一個波腹的 λ/4。
  • 拉管長與第幾個諧音，上面那條曲線會重新排列，右邊的波長、頻率、模態、波節數跟著跳。按最下面的諧音清單可以一個一個聽，最下面那顆按鈕是把所有諧音疊起來的音色。
  • 切到閉管再看一次清單——有幾列會變成灰的、打上刪除線。那些就是閉管吹不出來的音。

按「開始」，質點開始左右振動：密部和疏部在原地交替出現，波形本身不跑。

物理知識

兩條 lane 看的是同一件事

下面那條 lane 的每一顆質點，位置就是從上面那條曲線讀出來的：

\[\begin{aligned} x_{\text{質點}}(t) &= x_0 + A\cos\!\left(\frac{2\pi x_0}{\lambda}\right)\cos(\omega t) \\[2pt] \omega &= 2\pi f = \frac{2\pi v}{\lambda} \end{aligned}\]

波節的地方 $\cos\frac{2\pi x_0}{\lambda} = 0$，空氣從頭到尾不動（紅點）；波腹的地方它等於 $\pm 1$，動得最厲害（綠圈）。$v = 343$ m/s 是常溫空氣中的聲速。

上面那條曲線的縱軸是放大過的：0.6 公分的振幅放進 1.60 公尺長的管子裡，照原比例畫出來比一根頭髮還細。紅點永遠釘在平衡線上（波節本來就不動），綠圈跟著波腹上下跑。所以形狀（哪裡是波節、哪裡是波腹）看上面那條，動了多大看下面那條。

邊界條件決定一切

聲波是縱波，但「端點能不能動」這件事換了一種說法：

端點 空氣在這裡 駐波上的位置
開口（通大氣） 可以自由進出，壓力不變 波腹
封閉（被牆擋住） 貼著牆動不了 波節

整根管子要能穩定地站著一個駐波，兩端就必須各放一個波節或一個波腹——中間不夠放就是站不住。這一條推出來的結果，就是下面兩條式子。

開管：兩端都是波腹

一端波腹、另一端也是波腹，中間最省力的放法是「一個半波長」；再多放就依此類推：

\[L = n\frac{\lambda}{2} \quad\Longrightarrow\quad \lambda = \frac{2L}{n}, \qquad f = \frac{v}{\lambda} = n\frac{v}{2L}\]

$n$ 是任何正整數，所以頻率是 $f_1, 2f_1, 3f_1, \dots$——諧音比 1 : 2 : 3 : 4 : 5，一個都不缺。管長 1.60 公尺時基頻是

\[f_1 = \frac{343}{2 \times 1.60} = 107.2 \ \text{Hz}\]

閉管：一端波節、一端波腹

左端是波節、右端是波腹。一個半波長需要兩個波節（或兩個波腹），這裡湊不出來；能放進去的最短的一段是「波節到相鄰波腹 = 四分之一波長」：

\[L = n\frac{\lambda}{4}, \quad n = 1, 3, 5, 7, \dots \quad\Longrightarrow\quad f = n\frac{v}{4L}\]

管長一樣是 1.60 公尺時

\[f_1 = \frac{343}{4 \times 1.60} = 53.6 \ \text{Hz}, \qquad f = 53.6,\ 160.8,\ 268.0, \dots\]

基頻只剩開管的一半，而且往上跳的間隔是 $2f_1$ 不是 $f_1$——第 2、第 4、第 6 個諧音的位置上是空的。同樣的管長，閉管吹出來的聲音比開管低八度，而且音色比較「空」：缺少偶數諧音正是這個感覺的來源。

兩根管子擺在一起看

以 $L = 1.60$ m、$v = 343$ m/s 為例：

  開管 閉管
端點 兩端都是波腹 一端波節、一端波腹
管長與波長 $L = n\lambda/2$ $L = n\lambda/4$，$n$ 只能奇數
基頻 $f_1$ 107.2 Hz 53.6 Hz
諧音比 1 : 2 : 3 : 4 : 5 1 : 3 : 5 : 7 : 9
相鄰諧音間隔 $f_1$ $2f_1$
第 2 個諧音 214.4 Hz 吹不出來

畫面上預設是開管的第 2 個諧音：模態 $n = 2$、$\lambda = 1.600$ m、$f = 214.4$ Hz，管內有 2 個波節、3 個波腹。切到閉管、把「第幾個諧音」拉到 3，得到的是模態 $n = 5$、$\lambda = 1.280$ m、$f = 268.0$ Hz——同一個滑桿位置，兩根管子給的模態號碼不一樣，因為閉管跳過了偶數。

開口端，其實還要再長一點

真實的管子，開口端的波腹並不在管口那一刀切下去的地方，而是稍微探出管子外一點點，大約 $0.6r$（$r$ 是管半徑）：

\[L_{\text{有效}} = L + 0.6r\]

所以實際吹出來的頻率會比 $v/2L$ 算出來的低一點，管子愈細這個差別愈小。這一頁用的是理想模型，畫面上的數字就是 $v/\lambda$ 的結果，沒有把這一截補進去。這也解釋了為什麼真實的管樂器調音時，除了改變管長，還要動一下吹嘴或管口的形狀。

生活中的空氣柱

  • 🎺 管風琴：每一根管子是一根固定長度的空氣柱，管長決定音高。兩端開口的（開管音栓）音亮、一端封閉的（閉管音栓）音暗，差的就是那批失蹤的偶數諧音——所以管風琴要用兩種管子才能湊出完整的音色。
  • 🎵 直笛與笛子：按放指孔就是在改變「有效管長」，按住愈多孔管子愈短、頻率愈高。
  • 🍶 吹瓶口：對著空瓶口吹氣會有一個低音；倒進一些水，聲音就變高——水面上升，空氣柱變短。
  • 🚗 排氣管與風管：引擎的排氣脈衝、空調風管裡的氣流都會在管子裡激起駐波，出現一個固定的低頻嗡嗡聲。師傅把管子接長或加一段消音器，改的就是這根空氣柱的共振條件。

📊 實驗探究思考

  1. 同樣 1.60 公尺，開管的基頻是 107.2 Hz，閉管卻只有 53.6 Hz。為什麼閉管的基頻剛好是開管的一半？
  2. 為什麼閉管吹不出第 2、第 4、第 6 個諧音？從「一端是波節、一端是波腹」想想看，一個完整的半波長需要什麼。
  3. 開管的第 2 個諧音是 214.4 Hz，閉管的第 3 個諧音是 160.8 Hz。兩根管子一樣長，為什麼這兩個數字對不上？
  4. 把管長從 1.60 公尺拉到 2.00 公尺，右邊的頻率卡片會變大還是變小？先猜，再拉。
  5. 吹直笛時手指按放不同的孔，改變的是管子的哪一個量？按住愈多孔，音是變高還是變低？
