🔉 聲波的位移波與壓力波

實驗介紹

畫面上是同一根管子裡的同一股疏密，用兩條曲線畫出來：上面那條是空氣質點的 位移（正的是往右），下面那條是壓力變化（向上的是高於大氣壓，也就是密部）。 兩條曲線之間有幾條紅色的垂直虛線，把「位移為 0」的位置和「壓力最大」的位置連起來。

按「開始」，兩條曲線一起往右跑。盯住任何一條虛線看：它的上端永遠落在上面那條 曲線的平衡線上，下端永遠落在下面那條的波峰或波谷上——兩端從來沒有同時在波峰。 灰色和藍色的色帶標出管子裡哪一段被擠緊（藍＝密部、灰＝疏部）。

把「頻率」拉高，波長變短、虛線變密，下面的壓力曲線會跟著長高，而上面的位移 曲線高度不變；把「振幅」拉大，兩條曲線一起長高。中間那個「相隔 λ/4」的標記 量的是上面那條曲線從平衡位置走到最高點的距離——那就是兩條曲線的相位差。

這一頁是慢動作（和「聲音的產生與傳播」同一組數字，×170）。120 Hz 的聲音 一秒振動 120 次，畫面上的頻率、波長、聲速都是真值，只有時間走得多快不是。

物理知識

核心概念

聲波是縱波：空氣質點沿著管子前後振動，疏密沿著同一條線往前傳。同一股疏密 可以同時用兩個量來描述，而這兩個量相差四分之一個波長：

  • 位移 s：質點離開原來位置多遠（本頁向上畫成往右）。
  • 壓力變化 p：那一小段空氣比大氣壓高多少（密部）或低多少（疏部）。

擠得最緊的地方（密部），空氣被推離原本的位置了嗎？沒有——位移是 0。 質點只是在原地「前後擠」，被擠成一團的那一點反而不在動。

核心公式

壓力變化是位移的空間導數：

\[p \propto -\frac{\partial s}{\partial x}\]

兩個相鄰質點原本相距 $\Delta x$，位移之後變成 $\Delta x\left(1+\dfrac{\partial s}{\partial x}\right)$。 $\dfrac{\partial s}{\partial x}$ 是負的，代表後面的質點追上了前面的質點——距離縮短、 被擠緊，壓力就上升。所以壓力變化正比於位移曲線的斜率，而且差一個負號。

位移取 $s = A\sin(k(x-vt))$，代進去得到

\[p = -Ak\cos(k(x-vt))\]

$\sin$ 和 $\cos$ 相差 $90^\circ$，對應到空間上就是 $\lambda/4$：

位置 位移 s 壓力 p
密部中央 0 最大（正）
疏部中央 0 最小（負）
位移最大處 ±A 0

還有一個訊息藏在 $Ak$ 裡：壓力變化的振幅是位移振幅的 $k = \dfrac{2\pi f}{v}$ 倍。 所以頻率愈高，同樣的位移振幅對應的壓力變化愈大——把頻率拉高時下面那條 曲線會長高，就是這件事。

怎麼從畫面讀出來

畫面上的東西 代表什麼
上面那條藍色曲線 空氣質點的位移
下面那條黑色曲線 壓力變化（由位移的斜率算出）
紅色垂直虛線 位移為 0，同時是壓力的極值
虛線上端的紅點 質點正在平衡位置
虛線下端的紅點 那一點被擠得最緊或最鬆
藍色帶／灰色帶 密部（高壓）／疏部（低壓）
「相隔 λ/4」的括號 平衡位置到位移最高點的距離

兩個容易搞錯的地方

一、壓力最大的地方不是位移最大的地方。 密部中央的質點位移是 0，它旁邊 一點點的地方位移才最大——兩者相差剛好 $\lambda/4$。畫面上把虛線的兩端連起來 看就不會記錯：一端在平衡線、另一端在波峰。

二、壓力波不是另一條波。 它是同一條位移波的斜率，畫面上那條黑色曲線的 每一點都是上面那條藍色曲線在該處的陡峭程度。斜率是 0 的地方（位移最高、 最低）壓力變化就是 0；斜率最陡的地方（平衡位置）壓力變化最大。

生活中的聲波

  • 🔊 喇叭紙盆：往前推時把前方的空氣擠成密部，往後拉時讓出空間變成疏部，一推一拉就是一個週期
  • 🎤 麥克風：振膜被壓力變化推動，量到的其實是空氣的疏密；它不直接量質點走了多遠
  • 🪟 氣密窗：窗戶擋掉的是聲音傳進來的那股壓力變化，不是空氣跑進來
  • 💥 爆炸：近處的壓力變化可以比大氣壓高很多，那一瞬間的推力就是衝擊波

📊 實驗探究思考

  1. 紅色的垂直虛線為什麼一端落在上面那條曲線的平衡線上、另一端卻落在下面那條的波峰或波谷上？虛線可不可以兩端都落在波峰上？
  2. 把頻率從 100 Hz 拉到 180 Hz。上面那條曲線的高度有沒有變？下面那條呢？兩條曲線的高度比例跟著哪一個數字在動？
  3. 下面那條曲線的波峰，正好對到上面那條曲線的哪個位置？是最高點、最低點，還是平衡位置？
  4. 這根管子裡的空氣換成水（聲速 1500 m/s），同樣 120 Hz 的聲波，波長會變長還是變短？紅色的虛線會變多還是變少？
  5. 盯住管子裡某一顆固定的空氣質點。它通過原來位置的那一瞬間，那一點的壓力變化是最大、最小，還是 0？
  6. 喇叭的低音和高音一起送出來，哪一個在空氣裡造出的壓力變化比較大？（提示：壓力波的高度和 k = 2πf/v 有關）
