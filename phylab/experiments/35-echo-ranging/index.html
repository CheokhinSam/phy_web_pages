📣 回聲測距

實驗介紹

畫面上是一條路面：車在左邊、山壁在右邊，中間鋪著公尺刻度。按「開始」＝鳴笛，一條藍色箭頭從鳴笛點往右長出去，一路長到山壁；撞上之後折返，變成橘色的一條往回跑。車的頭頂上另有一支深色箭頭，那是車自己的速度。車從第一格就和聲音分家——聲音以 340 m/s 前進，車只有 20 m/s。

箭頭畫的就是聲音走過的路，一筆從鳴笛點畫到山壁、再折回車——去程走上面那條軌、回程走下面那條軌，在牆邊轉一個彎。尖端釘在聲音已經走到的地方，指的方向就是它正在走的方向；尖端碰到車的那一刻，就是聽到回聲。

車底下有三條距離尺，一條對一個量：藍色的去程（鳴笛點到山壁）、橘色的回程（山壁到回音的前緣，淡橘那一段是還沒回來的）、灰色的車走的（鳴笛點到車）。回程的左端永遠貼著回音的前緣。

回音與車之間有一條橘色虛線，兩端各一顆箭頭——那是「還差多遠」。它會在回音追上車的那一刻縮到零，車上跳出「聽到回聲了」。

  • 切「車往哪邊開」：駛向山壁是最常見的標準題；切到駛離山壁再按一次開始，比較兩次的時間與各段距離。
  • 拉「車速 v」和「鳴笛點到山壁 s₀」：整個橫軸會自動重新縮放，山壁永遠站在右緣。
  • 按「重設」：回到鳴笛前那一刻。

物理知識與公式

三個時刻

把座標釘在路面上：山壁永遠在 $x = s_0$，車在 $t = 0$ 時在 $x = 0$，以速度 $u$ 沿 $+x$ 前進（駛向山壁 $u = +v$、駛離山壁 $u = -v$）。

時刻 發生什麼事 式子
$t_1$ 聲音撞到山壁 $t_1 = s_0 / c$
$t$ 回音追上車，聽到了 $t = 2s_0 / (c + u)$

$t_1$ 只跟山壁多遠、聲音多快有關，跟車怎麼走完全無關——聲音走的就是 $s_0$ 這一段。

那條式子怎麼來的

聲音出發之後車還在走，所以回程的終點不是鳴笛點，而是車往前跑到的 $x = ut$。聲音走的路分成兩段：

\[c\,t = s_0 + (s_0 - u\,t)\]

畫面上那條箭頭就是這個等式：藍色的去程是 $s_0$、橘色的回程是 $s_0 - u\,t$，兩段接起來的總長剛好是 $c\,t$。去程是 $s_0$，回程是 $s_0 - u\,t$（車往前吃掉了 $ut$，所以回程比去程短）。展開移項：

\[(c + u)\,t = 2s_0\]

駛向山壁時 $u = +v$，就是常見的 $2s_0 = (c+v)t$；駛離山壁時 $u = -v$，同一個式子變成 $2s_0 = (c-v)t$。

兩個題型算一次

$s_0 = 360$ m、$v = 20$ m/s、$c = 340$ m/s：

題型 聽到回聲 t (s) 聲音總路程 (m) 車走的 (m) 回程 (m)
駛向 $u=+20$ 2.00 680 40 320
駛離 $u=-20$ 2.25 765 45 405

駛向那一列：聲音走了 680 m，其中去程 360 m、回程 320 m；車走了 40 m。把車走的和回程加起來，$40 + 320 = 360$，剛好是去程。

駛離那一列：車愈跑愈遠，回程變成 405 m，比去程還長；$360 + 45 = 405$，回程 = 去程 + 車走的。

同一個 360 m，答案一個變小一個變大，差別全在「車往哪邊走」那個正負號。

怎麼從畫面讀出來

  • 箭頭：藍色那一段是聲音往山壁走的路（去程），橘色那一段是回音往車走的路（回程）。箭尖釘著的那一格，就是聲音（或回音）已經走到的地方，而且整條箭頭的總長就是「聲音走過的總路程」。
  • 車頂上那支深色箭頭：那是車速 $v$——方向是車前進的方向，車速愈大它就愈長。聲音在飛的整段時間裡，車就是這樣一路走過去的。
  • 回音與車之間那條橘色虛線：那是「還差多遠」。它在回音追上車的那一刻縮到零——那一刻車上會跳出「聽到回聲了」。
  • 三條距離尺：把回程那條和去程那條比一比——駛向時回程短了一截、駛離時長了一截，而那一截剛好是灰色那條（車走的）。

容易搞錯的地方

  • 直接寫 $s = c\,t$（680 m）：那是聲音走的路，不是山壁的距離。
  • 寫 $s = c\,t / 2$（340 m）：這只有在車停著的時候才對——回程的終點是車，不是鳴笛點。
  • 以為聲音會跟著車跑：鳴笛之後，聲音的源頭就留在鳴笛點那一格，車自己開走了。
  • 這兩個錯在車速小的時候看起來「差不多」，車速開到 80 m/s 就很明顯——把車速拉到最大再跑一次。

生活中的回聲

山谷裡的回音、聲納、超聲波測距、倒車雷達都是同一件事：發一個短脈衝出去、量它多久回來。測距儀自己不動，所以距離就是 $c\,t / 2$；這一頁多了「車一邊走」，那條式子才變成 $(c+u)\,t = 2s_0$。

📊 實驗探究思考

  1. 車速 20 m/s、鳴笛點距山壁 360 m，按「開始」——幾秒之後聽到回聲？這段時間車走了多遠？
  2. 把「車往哪邊開」切成駛離山壁再按一次開始：時間變長還是變短？「車走過的距離」和「回程已經走了」兩張卡片，哪一個比較大？
  3. 把車速拉到 0 再按一次開始：幾秒聽到回聲？「車走過的距離」是多少？車頂上那支箭頭到哪去了？
  4. 撞上山壁之後，藍色那一段就不再變長了——它為什麼停在那裡？同一時間，橘色那一段和車頂那支箭頭各自在做什麼？
  5. 整條箭頭的總長是「聲音走過的總路程」680 m，而鳴笛點到山壁只有 360 m——多出來的那 320 m 是什麼？
