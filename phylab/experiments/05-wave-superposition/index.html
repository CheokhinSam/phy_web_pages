🪢 波的疊加與干涉

實驗介紹

同時從兩端各抖一個波浪出去。兩個波在繩子中間碰到的時候會發生什麼事？它們會撞歪嗎？會彈開嗎？

答案比你想的簡單：什麼都不會發生，它們只是直接加起來。

畫面上有三條繩子（其實是同一條繩子的三次紀錄疊起來）：最上面是脈衝 A，中間是脈衝 B，最下面是它們的和。最下面那條墊了兩條淡色虛線，就是上面兩條平移下來的形狀——可以直接看到「黑線高度 = 藍虛線 + 橘虛線」。

左邊可以調脈衝 A 的振幅、脈衝 B 的振幅、脈衝寬度 w，並選擇 B 是正脈衝還是負脈衝。把 B 切成負的，就是這個實驗最有趣的地方。

物理知識

核心概念

疊加原理：兩條波同時經過繩子上的同一點時，那一點的位移就是兩條波各自位移的和。

\[y(x,t) = y_1(x,t) + y_2(x,t)\]

這條式子看起來平凡到不像物理定律，但它是整個波動學的地基——干涉、駐波、繞射，甚至量子力學的波函數，全部靠它。原因是繩波的張力對位移是線性的：兩條波各自產生的力加起來就是總力，線性方程的解可以直接相加。

三種重疊的結果

重疊的情況 合成結果 名字
波峰對上波峰（同相） 位移相加，變成更大的波峰 建設性干涉
波峰對上波谷（反相） 位移相減，甚至完全抵消 破壞性干涉
部分重疊 各點各自相加，形狀是歪的 一般情形

把「B 是正還是負」切成負的、兩個振幅調成一樣大，就會看到完全抵消：兩條脈衝完全重疊的那一瞬間，整條繩子是平的。

一個很容易誤會的地方

繩子平掉的時候，能量並沒有消失。 那一瞬間兩條波各自都還在，能量都還在繩子上，只是剛好互相抵消。證據就是再過一瞬間它們就分開了，兩條脈衝原封不動地繼續前進——如果能量真的消失，分開之後就不會再有脈衝了。能量守恆在這裡的表現是「波形各自保留」，不是「合成之後留下什麼」。

疊加不是碰撞

粒子對撞是「撞完之後東西變了」——速度變了、方向變了、可能碎掉。波不一樣：相遇之前是什麼形狀，分開之後還是什麼形狀，兩條波互相穿過，好像對方不存在一樣。

這就是為什麼無線電波可以同時在空中傳遞幾千個電台——它們互相穿過，只有在你的收音機把其中一個挑出來的時候，你才知道有幾個電台。

生活中的疊加

  • 🌊 海邊的瘋狗浪：好幾個方向不同的浪偶然疊在一起，波高可以突然變成好幾倍
  • 🎧 抗噪耳機：量到外面的噪音，立刻播一個完全相反的聲波出去，兩者相消——就是這個實驗的負脈衝
  • 📡 無線電：成千上萬個電台的訊號在空中疊加、互相穿過，各自到達自己的收音機

📊 實驗探究思考

  1. 兩條脈衝疊在一起的時候，繩子上的位移是怎麼決定的？把下面那條合成波的黑色曲線，和兩條淡色虛線的高度對一照，你發現什麼關係？
  2. 把「脈衝 B」切成負脈衝，讓兩條一上一下完全重疊。那一瞬間繩子是平的——繩子上的能量消失了嗎？放開之後兩條脈衝還在嗎？
  3. 兩條脈衝分開之後，形狀和相遇之前比起來有沒有一點不一樣？這告訴你「疊加」和「碰撞」有什麼根本差別？
  4. 如果兩條脈衝的波速不一樣（例如接到不同粗細的繩子上），它們還會在正中間相遇嗎？為什麼？
  5. 海邊兩個浪疊起來會變成更大的浪，這和這個實驗有什麼關係？
