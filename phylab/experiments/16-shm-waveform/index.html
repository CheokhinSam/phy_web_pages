🌀 簡諧運動圖像

實驗介紹

本實驗讓你觀察簡諧運動的位移-時間圖像。上方是彈簧振子動畫，下方即時繪製 x-t 圖。你可以調整相位 φ（0、π/2、π、3π/2、2π），觀察波形如何平移，深入理解公式 $x(t) = A\sin(\omega t + \phi)$ 中每個符號的意義。

按「開始」後小球開始振動，紅色軌跡記錄實際位移，藍色虛線顯示理論曲線。調整相位滑桿，小球會跳到對應的起始位置。

物理知識

核心概念

簡諧運動的位移可以用一個正弦函數來描述：

\[x(t) = A\sin(\omega t + \phi)\]

這個公式告訴你小球在任何時刻的位置：

  • A（振幅）：小球離平衡位置最遠的距離。振幅越大，擺動範圍越大。
  • ω（角頻率）：決定振動快慢。ω 越大，來回擺動越快。$\omega = \sqrt{k/m}$
  • φ（相位）：決定振動的「起始狀態」。

相位的意義

相位 φ 控制的是「振動從哪個階段開始」：

相位 φ 起始位置 起始速度 白話說
0 平衡位置 向右（最大） 從中間衝出去
π/2 最右端 (+A) 0 從最右邊靜止放開
π 平衡位置 向左（最大） 從中間往左衝
3π/2 最左端 (-A) 0 從最左邊靜止放開
2π 平衡位置 向右（最大） 同 φ=0，回到起點

就像兩個人盪鞦韆：同時從最高點出發（φ 相同）會同步擺動；一個從最高點、一個從最低點出發（φ 差 π），動作完全相反。

從圖表看出端倪

  • 藍色虛線：理論曲線，根據公式畫出的正弦波
  • 紅色實線：模擬的實際軌跡（無阻尼時兩者完全重合）
  • 紅點：小球此刻在圖上的位置
  • 調整 φ 時，小球會跳到新的起始位置，藍色曲線也會平移

生活中的相位

  • 🎵 音樂和弦：兩個音叉同時振動，相位差決定聲音是加強還是抵消
  • 🌊 海浪干涉：兩道波浪相遇時，相位相同會疊高，相位相反會抵消
  • 💡 降噪耳機：產生和噪音相位差 π 的聲波，兩者抵消達到靜音效果

📊 實驗探究思考

  1. 為什麼 x-t 圖是正弦波形？它和彈簧的伸縮有什麼對應關係？
  2. 把相位 φ 從 0 調到 π/2，小球的起始位置有什麼不同？
  3. 相位 φ = π 和 φ = 0 的波形有什麼關係？為什麼？
  4. 改變振幅 A，波形有什麼變化？改變彈簧常數 k 呢？
  5. 如果同時改變 k 和 m 但保持 k/m 不變，週期會變嗎？
