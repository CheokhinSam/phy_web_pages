🔄 電磁感應與楞次定律

實驗介紹

磁鐵不動的時候，線圈上一點電壓都沒有；磁鐵一動，電就來了。為什麼？

磁鐵來回掃過線圈，穿過線圈的磁通量跟著改變，於是在線圈上感生出電壓——這件事完全不需要電池。畫面上分成三塊：磁鐵與線圈（會顯示線圈被感應成什麼極）、左下角的 Φ–t 與 ε–t 圖、右下角的即時讀數。

按「開始」，然後拉「往復頻率」——磁通量的最大值完全沒變，但感應電壓明顯變大。

物理知識

核心概念

變的才有效。 只有穿過線圈的磁通量 $\Phi$ 正在改變時才有感應電動勢。磁鐵放在線圈旁邊不動——不管放多近、磁鐵多強——$\Phi$ 是個定值，$\frac{d\Phi}{dt} = 0$，$\varepsilon = 0$。圖上那三個「Φ 最高但 ε = 0」的瞬間就是同一件事：Φ 到極值的那一刻，它的變化率剛好是零。

Φ 正比於磁鐵強度與匝數，ε 正比於「Φ 變得多快」。 調「磁鐵強度」會把 Φ 和 ε 一起放大；調「往復頻率」只放大 ε，Φ 的峰值一動也不動。這兩顆滑桿的差別就是 $\Phi$ 和 $\frac{d\Phi}{dt}$ 的差別。

楞次定律：線圈永遠跟造成它的那件事作對。 磁鐵靠近，穿過的磁通量增加，線圈就把自己變成同極，把磁鐵往外推；磁鐵離開，磁通量減少，線圈就翻成異極把它拉回來。畫面左下角「線圈左端」是 N 還是 S 就是這件事——它一定跟你手上的動作相反。

它不是「反抗」，它是「守住」。 線圈這樣做是在阻止磁通量改變，而阻止的過程本身要有能量：推斥磁鐵要作功，這份功就是電能的來源。發電機就是這樣把機械能換成電能的。

核心公式

\[\Phi = \int \vec B \cdot d\vec A \qquad \varepsilon = -N\frac{d\Phi}{dt} \qquad I = \frac{\varepsilon}{R}\]
符號 意思
$\Phi$ 穿過單一圈的磁通量（Wb）
$\vec B$ 磁場（T）
$N$ 線圈匝數
$\varepsilon$ 感應電動勢（V）
負號 楞次定律：感應出來的方向總是反對磁通量的改變

從畫面看出端倪

  • 圖上兩條曲線對得起來：紅線 ε 是藍線 Φ 的斜率。Φ 到頂／到谷的地方紅線穿過零，Φ 過零的地方紅線最陡
  • ⊙ 和 ⊗ 在磁鐵靠近與離開時互換，位置在線圈的上下緣——側面圖裡，最高點的導線是穿出／穿入畫面的
  • 線圈左端顯示 N 極時，磁鐵一定是靠近中；顯示 S 極時一定是離開中。這個對應不會有例外
  • 「N 極到線圈」越近，Φ 越大，但 ε 要看它跑得多快——最靠近的那一瞬間 ε 反而是 0

生活中的電磁感應

  • ⚡ 發電機：水力、火力、核能最後都是轉同一根軸，靠線圈在磁場裡轉來發電
  • 🚇 捷運的再生煞車：減速時把馬達當發電機，這一份電能就是楞次定律「拉住」的結果
  • 🍳 電磁爐：鍋底被變動的磁場感應出渦電流，直接在鍋子裡發熱，爐面本身不熱
  • 💳 無線充電與感應卡：手機背蓋裡就是一顆線圈，靠變動的磁場隔空取電

📊 實驗探究思考

  1. 圖上 Φ 最高的那三個瞬間，ε 都是 0。磁通量最大不正是「感應最強」嗎？為什麼反而是 0？
  2. 把「往復頻率」拉快，Φ 的最大值沒變，ε 卻變大了。這件事用 $\varepsilon = -N\frac{d\Phi}{dt}$ 怎麼解釋？
  3. 磁鐵靠近時線圈推它、離開時線圈拉它——它從來沒有幫過磁鐵。線圈這樣做有什麼好處？
  4. 如果把磁鐵換成「慢慢靠近、停在那裡不動」，ε 會是多少？發電機為什麼不能靠一個靜止的磁鐵發電？
