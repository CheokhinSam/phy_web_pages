🚶🚲🚗 參考系

實驗介紹

本實驗展示參考系對運動描述的影響。畫面中有：

  • 🚲 自行車：藍色，向右慢速行駛
  • 🚗 汽車：紅色，向右快速行駛
  • 🚶 行人：綠色，向左步行

透過切換參照物（地面 / 自行車 / 汽車），觀察同一事件的不同描述。

物理知識

什麼是參考系？

參考系是描述物體運動時選取的參照物。選不同的參照物，對同一事件的描述會不同。

關鍵觀察

參照物 自行車 汽車 行人
地面 向右慢 向右快 向左
自行車 靜止 向右（較慢） 向左（更快）
汽車 向左後退 靜止 向左（更快）

速度變換

\[\vec{v}_{相對} = \vec{v}_{絕對} - \vec{v}_{參照}\]

核心結論

  1. 運動是相對的 — 沒有「絕對靜止」
  2. 參照物決定描述 — 選擇不同，結論不同
  3. 方向也可能改變 — 向左的行人，在不同參考系中速度大小會變

生活中的例子

  • 坐車時看窗外：樹木在「後退」
  • 兩車並行：對方看起來「不動」
  • 迎面走來的人：在你眼中越來越快

📊 實驗探究思考

  1. 以地面為參照時，自行車、汽車和行人的速度分別是多少？
  2. 換到自行車參考系後，汽車和行人的速度有什麼變化？
  3. 為什麼同一個人，在不同參考系中速度不同？
  4. 行人向左走，在不同參考系中方向會改變嗎？
