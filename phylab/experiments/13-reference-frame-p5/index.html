🚶🚲🚗 參考系（p5.js 版）

實驗介紹

這是用 p5.js 和 KaTeX 重做的參考系實驗。功能與原版相同，但底層技術不同：

  • p5.js：創意程式語言，繪圖 API 比原生 Canvas 更簡潔
  • KaTeX：數學公式渲染引擎，比 MathJax 更輕量快速

畫面中有三個移動的物體：🚲 自行車（藍色，向右慢速）、🚗 汽車（紅色，向右快速）、🚶 行人（綠色，向左步行）。切換參照物，觀察同一事件的不同描述。

物理知識

什麼是參考系？

參考系是描述物體運動時選取的參照物。選不同的參照物，對同一事件的描述會不同。

速度變換公式

\[\vec{v}_{相對} = \vec{v}_{絕對} - \vec{v}_{參照}\]

特性 原版（Canvas + MathJax） 新版（p5.js + KaTeX）
繪圖 原生 Canvas 2D API p5.js 簡化 API
