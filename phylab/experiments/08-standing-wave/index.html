🪢 駐波與諧音

實驗介紹

彈吉他的人都知道：弦調緊一點，音就變高。但為什麼一根弦只能發出特定的幾個音，而不是隨便什麼頻率都可以？

畫面上一條兩端固定的繩子，我們不送波進去，而是直接讓它以某個模式振動起來。答案是：只有波長符合 $L = n\lambda/2$ 的振動活得下來，其他的會自己和自己打架、互相抵消。

畫面上有兩條 lane：上面是駐波本身（紅色小點是永遠不動的節點），下面是它的分解——拆成兩個方向相反的行進波，再加上它們的和。那條和會跟上面那條駐波一模一樣。

左邊可以選兩端都固定或左端固定、右端自由，並調整模式 n（1 到 5）和腹點振幅 A。

物理知識

波長被繩長鎖死

兩端都固定，所以兩端位移永遠是零。能同時滿足 $x = 0$ 與 $x = L$ 都是零、而且一直保持下去的波形只有一種：

\(y(x,t) = A\sin(kx)\cos(\omega t)\) \(k = \frac{n\pi}{L} \qquad (n = 1, 2, 3, \dots)\)

因為 $k = 2\pi/\lambda$，代進去就得到弦長裡剛好要塞進整數個半波長：

\(L = n\frac{\lambda}{2} \qquad \lambda = \frac{2L}{n}\) \(f = \frac{v}{\lambda} = \frac{nv}{2L}\)

弦長裡剛好要塞進整數個半波長。 塞不進整數個的波會在端點留下不為零的位移，就活不下去。$n = 1$ 叫基頻，$n = 2, 3, \dots$ 叫泛音或諧音，頻率剛好是基頻的整數倍——頻率被鎖在整數倍上，耳朵才聽得出和諧，這就是樂器有音高的原因。

節點與腹點

位置 名字 位移 在哪裡
永遠不動 節點 0 $x = 0,\ \frac{L}{n},\ \frac{2L}{n},\ \dots,\ L$，共 $n+1$ 個
動得最厲害 腹點 最大 $= A$ 兩個節點正中間

相鄰兩個節點的距離永遠是 $\lambda/2$——這是駐波最好用的特徵，在畫面上量出節點間距就等於量到了半個波長。

駐波其實是兩個行進波

駐波不是一種新的波，它就是兩個方向相反的行進波疊加出來的：

\(\tfrac{A}{2}\sin(kx - \omega t) + \tfrac{A}{2}\sin(kx + \omega t)\) \(= A\sin(kx)\cos(\omega t)\)

左邊那兩項就是下面那條 lane 畫的兩條淡色波形，各以 $v$ 往相反方向跑。相加之後時間的部分只剩 $\cos(\omega t)$、位置的部分只剩 $\sin(kx)$，兩者分離了，所以波形不會前進，只是原地上下跳。兩條行進波各只有 $A/2$，在腹點同相相加變成 $A$。

一端固定、一端自由

固定端要求位移為零，自由端要求斜率為零，兩個條件一起解得

\[L = (2n-1)\frac{\lambda}{4}\]

也就是只塞得進奇數個四分之一波長，頻率是基頻的 1、3、5、7…倍。這就是為什麼同樣長度的管子，一端開口（笛子）和兩端封閉吹出來的音高不一樣——開口端是自由端、封閉端是固定端，泛音結構天生就不一樣。

生活中的駐波

  • 🎸 吉他：按住弦的不同位置就是改變 $L$，於是改變了所有諧音的頻率——所以按弦就能換音高
  • 🎹 鋼琴：同一根弦上同時有好幾個諧音在響，它們的相對強弱決定了「這是鋼琴還是小提琴」
  • 🌉 橋樑與高樓的共振：風或地震的頻率如果剛好對上結構的某個模式，振幅會累積得很大——工程師必須確保結構的自然頻率避開常見的風速與地震頻率

📊 實驗探究思考

  1. 整條繩子從頭到尾都在上下跳，只有紅點那幾個地方完全不動。這些紅點的位置有什麼規律？量量看相鄰兩點的距離。
  2. 把模式 n 從 1 調到 5，波長變成原來的幾分之幾？頻率變成幾倍？兩者的變化方向為什麼相反？
  3. 下面那條 lane 的兩條淡色波形一直往相反方向跑，但它們相加之後的黑線卻停在原地。為什麼會這樣？
  4. 為什麼只有 λ = 2L/n 這幾個波長能留下來？如果波長是 2L/2.5，繩子上會發生什麼事？（提示：想想繩子兩端必須滿足什麼條件）
  5. 「一端固定、一端自由」時，只有奇數倍的頻率能共振。同樣的道理，為什麼笛子（一端開口）和簫（兩端封閉）吹出來的音高不一樣？
