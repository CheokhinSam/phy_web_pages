⚙️ 直流電動機

實驗介紹

為什麼電動機不會一直加速下去？

通電的線圈在磁場中受力，開始旋轉。如果照「電壓越高 → 電流越大 → 力越大 → 轉越快」推下去，轉速應該無限制上升。但真實的馬達會停在一個固定的轉速。原因是：線圈一轉起來，自己就變成一台發電機。它在磁場中掃過磁力線，產生一個跟電源反向的電壓——反電動勢——把電流壓下去。

按「開始」，看左下角的電流曲線從啟動電流掉到穩態值，右下角的三根長條是一個電源分給兩個去向：機械輸出和線圈發熱。

物理知識

核心概念

線圈靜止時，電流只受電阻限制。 這時 $I = \dfrac{V}{R}$，叫做啟動電流。馬達剛通電的那一瞬間就是這個狀態，所以啟動電流最大——家裡的馬達啟動時燈會閃一下，就是這個電流在拉。

線圈轉起來之後，它自己發電。 線圈在磁場中轉動，穿過它的磁通量不斷改變，於是有感應電動勢。這個電動勢的方向由楞次定律決定——它反對造成它的變化，也就是反對電源推電流，所以叫反電動勢，記作 $\varepsilon_{\text{back}}$。

反電動勢把電流壓住，轉速就自動收斂。 轉得越快，反電動勢越大，能推動的電流就越小；電流小、轉矩就小。轉速會一直上升到「電磁轉矩剛好抵得過摩擦」為止，那之後就不再加速。

能量的帳要算平。 電源給的功率是 $VI$，其中一部分變成線圈的熱，剩下的才是機械輸出：

\[VI = \varepsilon I + I^2R\]

這條是恆等式，不是「大約相等」——畫面右下那三根長條，上面一根和下面兩根加起來一樣長。

核心公式

\[\varepsilon_{\text{back}} = NBA\omega \qquad I = \frac{V - \varepsilon_{\text{back}}}{R} \qquad \tau = NBAI\]
符號 意思
$V$ 電源電壓（V）
$N$ 線圈匝數
$B$ 磁場（T），由 N 極指向 S 極
$A$ 線圈的面積（m²）
$\omega$ 角速度（rad/s）—— 轉得越快，反電動勢越大
$\varepsilon_{\text{back}}$ 反電動勢（V），就是線圈自己的發電機
$\tau$ 電磁轉矩（N·m）

注意 $NBA$ 在三個式子裡都出現，它同時是「每單位電流的轉矩」也是「每單位角速度的反電動勢」——同一台馬達，這兩個數字必然相等，這正是能量守恆在這裡的長相。

從畫面看出端倪

  • 啟動那一瞬間電流衝到最大，然後往下掉到穩態值
  • 線圈兩端的 ⊙ 和 ⊗ 每半圈互換一次位置——那是換向器在做的事。少了它，線圈過了死點就會被往反方向推，只會前後晃動，轉不起來
  • 兩條功率長條的接縫：機械輸出 + 發熱，剛好等於上面那根電源輸入
  • 負載調重：轉速下降、反電動勢變小、電流上升 —— 爬坡的腳踏車就是這樣
  • 效率卡片顯示 $\varepsilon_{\text{back}} / V$：轉得越快效率越高，因為發熱那一項變小了

生活中的電動機

  • 🚇 捷運的再生煞車：減速時把馬達當發電機用，反過來把電送回電網
  • 🧺 洗衣機卡住會燒掉：卡住時 $\omega = 0$，反電動勢是 0，電流衝回啟動電流，全部變成熱
  • 🔌 啟動電流：馬達啟動電流可以是運轉電流的 5 倍以上，這就是為什麼大功率馬達要用降壓啟動
  • 🚗 電動車的動能回收：跟捷運是同一個原理，只是儲存的地方從電網變成電池

📊 實驗探究思考

  1. 按開始的瞬間電流最大，然後一路往下掉。掉下來的那個「煞車」是什麼？
  2. 把「負載」調重，轉速下降、電流反而上升。這跟腳踏車爬坡要更用力有什麼關係？
  3. 電源的功率 V·I 和「機械輸出 + 發熱」兩根長條加起來一樣長。如果線圈是超導體（R = 0），效率會是多少？
  4. 馬達卡住不轉的時候（例如洗衣機被衣服纏住），發熱功率會變成多少？為什麼會燒起來？
