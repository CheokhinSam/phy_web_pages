📈 位移時間圖

實驗介紹

這個實驗讓你選擇不同的運動模式（等速、等加速度、等減速、分段變速），然後即時看到小車在路上跑和對應的位移-時間圖（x-t 圖）。圖上會畫出一個直角三角形，把「斜率」實際量給你看——水平股是經過的時間，垂直股是這段時間的位移，兩者相除就是速度。

圖上那條灰色虛線是這個運動從頭到尾的完整軌跡，按「開始」之前就先畫好當底稿；按下「開始」之後，藍色實線才會沿著它一段一段長出來。所以任何時刻你都可以對照：實線是「已經跑過的」，虛線是「接下來要跑的」。虛線只是底稿，不是數據。

物理知識

📐 圖表三部曲

同一個運動可以畫成三張圖，差別只在縱軸放什麼：

實驗 縱軸 這張圖的重點
03 x-t 圖（你在這裡） 位移 x 斜率 = 速度
04 v-t 圖 速度 v 斜率 = 加速度、面積 = 位移
17 a-t 圖 加速度 a 面積 = 速度變化

三頁用的是同一台小車、同一組運動模式，所以同一個模式在三張圖上一定對得起來。

核心概念

位移-時間圖（x-t 圖）是用來記錄「物體在不同時間點的位置」的圖表。X 軸是時間，Y 軸是位移。

最重要的觀念：x-t 圖的斜率 = 速度。

  • 斜率是正的 → 物體往前走
  • 斜率是負的 → 物體往後走
  • 斜率是 0 → 物體靜止不動
  • 斜率越大 → 速度越快

核心公式

等速運動：

\[x = v_0 \cdot t\]

等加速度運動：

\[x = v_0 t + \frac{1}{2}at^2\]
  • $x$：位移（從起點算起的距離和方向）
  • $v_0$：初速度（一開始的速度）
  • $a$：加速度（速度每秒變化多少）
  • $t$：時間

從圖表看出端倪

運動模式 x-t 圖形狀 斜率的意思
等速運動 斜直線 斜率固定 → 速度不變
等加速度運動 往上彎的曲線（凹向上） 斜率越來越大 → 速度越來越快
等減速運動 往下彎的曲線，停下來之後變成水平線 斜率越來越小，最後為 0 → 速度歸零
分段變速 往上彎 → 直線 → 翻過去往下掉 → 再變平 每個轉折就是換一次速度；斜率變負 → 車子往回走，最後煞停

圖上那個三角形就是斜率。把「垂直股 ÷ 水平股」算出來，會發現它剛好等於右側數據面板上的速度——這不是巧合，這就是斜率的定義。

生活中的位移時間圖

  • 🚶 走路去學校：如果你用固定速度走，x-t 圖是一條斜直線
  • 🚗 紅燈起步：汽車從靜止開始加速，x-t 圖是一條往上彎的曲線
  • 🛗 搭電梯：電梯勻速上升時是斜直線，到達樓層減速時變成平緩的曲線
  • 🏃 賽跑衝刺：選手從起跑加速到全速，x-t 圖先彎後直

📊 實驗探究思考

  1. 為什麼等速運動的 x-t 圖是一條直線，而等加速度運動的 x-t 圖是曲線？圖形上的「斜率」對應到什麼？
  2. 把初速度設成 0、加速度設成 2 m/s²，觀察圖形。如果加速度變成 4 m/s²，圖形會怎麼變？為什麼？
  3. 選「等減速運動」，觀察車子停下來之後圖形會怎樣。為什麼圖形變成水平線了？
  4. 切到「分段變速」，注意第三段圖形開始往下彎、最後變回水平。斜率變成負的代表車子發生了什麼事？圖形最後為什麼又變平了？
  5. 三部曲對照：同一個「等加速度運動」，在 x-t、v-t、a-t 三張圖上分別是什麼形狀？把三個實驗頁面並排打開來看看。
