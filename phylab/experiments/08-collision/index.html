💥 兩球碰撞與動量守恆

實驗介紹

你有沒有打過撞球？當母球撞上子球的那一刻，速度瞬間改變——這就是碰撞。

這個實驗讓你觀察兩顆球在無摩擦水平面上碰撞的過程。你可以調整兩顆球的質量和初速度，選擇碰撞的類型，觀察碰撞後的速度變化，並驗證動量守恆定律。

物理知識

什麼是動量？

動量就是「運動的量」，等於質量乘以速度：

\[p = m \times v\]
  • $p$：動量（kg·m/s）
  • $m$：質量（kg）
  • $v$：速度（m/s）

質量越大、速度越快，動量就越大。

動量守恆定律

在沒有外力的情況下，碰撞前的總動量一定等於碰撞後的總動量：

\[m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'\]

這是物理學最基本的定律之一，不管碰撞多複雜都成立！

碰撞類型

類型 恢復係數 $e$ 現象 例子
完全彈性 1.0 動能也守恆，球分開 撞球、原子碰撞
部分彈性 0~1 動能部分損失 篮球彈地
完全非彈性 0 兩球粘在一起 子彈射入木塊

恢復係數

\[e = \frac{v_2' - v_1'}{v_1 - v_2}\]
  • $e = 1$：完全彈性（像撞球）
  • $e = 0$：完全非彈性（兩球粘在一起）

📊 實驗探究思考

  1. 碰撞前和碰撞後，總動量有沒有改變？為什麼？
  2. 把球2的質量調到很大（像一面牆），球1撞上去會怎樣？
  3. 什麼是「完全彈性碰撞」和「完全非彈性碰撞」？它們最大的差別在哪裡？
  4. 為什麼打撞球時，母球撞到子球後會停下來？這跟什麼條件有關？
