EXP_04

📈 速度時間圖

實驗介紹

這個實驗讓你選擇不同的運動模式（等速、等加速度、等減速、分段變速），然後即時看到小車在路上跑和對應的速度-時間圖（v-t 圖）。圖上會同時畫出兩個東西：量斜率的直角三角形，以及曲線和時間軸之間塗色的面積。

圖上那條灰色虛線是這個運動從頭到尾的完整軌跡，按「開始」之前就先畫好當底稿；按下「開始」之後，藍色實線才會沿著它一段一段長出來，著色的面積也跟著長。所以任何時刻你都可以對照：實線是「已經跑過的」，虛線是「接下來要跑的」。虛線只是底稿，不是數據。

物理知識

📐 圖表三部曲

同一個運動可以畫成三張圖，差別只在縱軸放什麼：

實驗 縱軸 這張圖的重點
03 x-t 圖 位移 x 斜率 = 速度
04 v-t 圖（你在這裡） 速度 v 斜率 = 加速度、面積 = 位移
17 a-t 圖 加速度 a 面積 = 速度變化

三頁用的是同一台小車、同一組運動模式，所以同一個模式在三張圖上一定對得起來。

核心概念

速度-時間圖（v-t 圖）是用來記錄「物體在不同時間點的速度」的圖表。X 軸是時間，Y 軸是速度。

最重要的觀念：

  • v-t 圖的斜率 = 加速度

  • v-t 圖底下的面積 = 位移

  • 斜率是正的 → 物體在加速
  • 斜率是負的 → 物體在減速
  • 斜率是 0 → 物體等速運動
  • 斜率越大 → 加速度越大

核心公式

等加速度運動：

\[v = v_0 + at\]
  • $v$：速度（現在的速度）
  • $v_0$：初速度（一開始的速度）
  • $a$：加速度（速度每秒變化多少）
  • $t$：時間

從圖表看出端倪

運動模式 v-t 圖形狀 斜率的意思
等速運動 水平線在 v₀ 斜率 = 0 → 加速度為 0
等加速度運動 往上斜的直線 斜率固定且為正 → 加速度不變
等減速運動 往下斜的直線，降到 0 之後貼在時間軸上 斜率為負；速度歸零後車子靜止
分段變速 上升 → 水平 → 下降，第三段穿過時間軸 → 回升到 0 每個轉折就是換一次加速度

圖上那個三角形就是斜率。把「垂直股 ÷ 水平股」算出來，會發現它剛好等於右側數據面板上的加速度。

v-t 圖的面積 = 位移

這是 v-t 圖最特別的地方：圖形底下的面積就是位移！

  • 面積在時間軸上方 → 正位移（往前走）
  • 面積在時間軸下方 → 負位移（往後走）
  • 面積越大 → 位移越大

生活中的速度時間圖

  • 🚗 紅燈起步：汽車從靜止開始加速，v-t 圖是一條往上斜的線
  • 🛗 搭電梯：電梯勻速上升時是水平線，到達樓層減速時變成往下斜的線
  • 🏃 賽跑衝刺：選手從起跑加速到全速，v-t 圖先斜後平
  • 🚲 腳踏車煞車：捏煞車後速度越來越慢，v-t 圖是一條往下斜的線

📊 實驗探究思考

  1. 為什麼等速運動的 v-t 圖是一條水平直線，而等加速度運動的 v-t 圖是斜線？
  2. 把初速度設成 0、加速度設成 2 m/s²，觀察圖形。如果加速度變成 4 m/s²，圖形會怎麼變？為什麼？
  3. 選「等減速運動」，觀察車子停下來之後圖形會怎樣。為什麼圖形變成水平線了？
  4. v-t 圖底下的「面積」代表什麼意思？把數據面板上的「圖下面積」和「位移」兩格對一對，你發現什麼？
  5. 三部曲對照：切到「分段變速」，注意曲線在第三段穿過時間軸。同一個運動的 x-t 圖和 a-t 圖在這時候各是什麼樣子？
