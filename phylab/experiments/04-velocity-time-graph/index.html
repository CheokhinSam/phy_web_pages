📈 速度時間圖

實驗介紹

你有沒有想過，如果把你跑步的過程畫成一張「速度-時間」圖，會長什麼樣子？如果你用固定速度跑，圖形是一條水平線；如果你越跑越快，圖形就會變成一條往上斜的線！

這個實驗讓你選擇不同的運動模式（等速、加速、減速、靜止），然後即時看到物體的運動和對應的速度-時間圖（v-t 圖）。你可以觀察圖形的形狀，理解「斜率」代表加速度，「面積」代表位移。

物理知識

核心概念

速度-時間圖（v-t 圖）是用來記錄「物體在不同時間點的速度」的圖表。X 軸是時間，Y 軸是速度。

最重要的觀念：

  • v-t 圖的斜率 = 加速度

  • v-t 圖底下的面積 = 位移

  • 斜率是正的 → 物體在加速
  • 斜率是負的 → 物體在減速
  • 斜率是 0 → 物體等速運動
  • 斜率越大 → 加速度越大

核心公式

等加速度運動：

\[v = v_0 + at\]
  • $v$：速度（現在的速度）
  • $v_0$：初速度（一開始的速度）
  • $a$：加速度（速度每秒變化多少）
  • $t$：時間

從圖表看出端倪

運動類型 v-t 圖形狀 原因
靜止 水平線在 0 速度一直是 0
等速 水平線在 v₀ 速度固定不變
加速 往上斜的直線 速度均勻增加
減速 往下斜的直線 速度均勻減少

v-t 圖的面積 = 位移

這是 v-t 圖最特別的地方：圖形底下的面積就是位移！

  • 面積在時間軸上方 → 正位移（往前走）
  • 面積在時間軸下方 → 負位移（往後走）
  • 面積越大 → 位移越大

生活中的速度時間圖

  • 🚗 紅燈起步：汽車從靜止開始加速，v-t 圖是一條往上斜的線
  • 🛗 搭電梯：電梯勻速上升時是水平線，到達樓層減速時變成往下斜的線
  • 🏃 賽跑衝刺：選手從起跑加速到全速，v-t 圖先斜後平
  • 🚲 腳踏車煞車：捏煞車後速度越來越慢，v-t 圖是一條往下斜的線

📊 實驗探究思考

  1. 為什麼等速運動的 v-t 圖是一條水平直線，而加速度運動的 v-t 圖是斜線？
  2. 把初速度設成 0、加速度設成 2 m/s²，觀察圖形。如果加速度變成 4 m/s²，圖形會怎麼變？為什麼？
  3. 選「減速運動」模式，觀察物體停下來之後圖形會怎樣。為什麼圖形變成水平線了？
  4. 想想看，v-t 圖底下的「面積」代表什麼意思？試著用生活中的例子解釋。
